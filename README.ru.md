# gcBuild: конструктор конфигов для gcsim

[English version](README.md)

Локальный сайт для сборки и запуска конфигов [gcsim](https://gcsim.app) (симулятор урона Genshin Impact) без
ручного написания скрипта. Билды собираются кнопками (KQMS или из своих артефактов), ротация — кликами по
навыкам или текстом вроде `HuTao E 10N2CD Q`, а сим запускается прямо на сайте.

## Установка на новый компьютер (Windows)

1. Установи [Node.js](https://nodejs.org), версию **LTS**. Больше ничего не нужно (ни Python, ни Go).
2. Скачай проект: `git clone https://github.com/mirfeed/gcBuild.git` или на GitHub *Code → Download ZIP*
   и распакуй.
3. Один раз запусти **`setup.bat`**: он ставит npm-пакеты и скачивает gcsim в папку `tools/`. Нужен интернет.
4. Дальше каждый раз запускай **`start.bat`**: сайт откроется на http://localhost:5179/.
   Пока сайт открыт, окно `start.bat` не закрывай — в нём работает сервер.

Нужна версия Node **20.19+ или 22.12+**. Если стоит старее, `setup.bat` / `start.bat` скажут об этом.

### Обновление и где лежат твои данные

Импортированные артефакты и *My builds* хранятся в папке `userdata/`, сохранённые отряды — в `teams/`
(внутри папки проекта). Обновление их не трогает:

- скачивал через `git clone` — обновляйся командой `git pull`;
- скачивал ZIP — распакуй новую версию и скопируй в неё папки `userdata/` и `teams/` из старой, потом
  запусти `setup.bat`.

Так же переносятся данные на другой компьютер: скопировать эти две папки.

## Как пользоваться

### Отряд и билды

У каждого персонажа в отряде есть три режима статов:

- **KQMS** — кнопка генерирует сабстаты по KQM Standards (как оптимизатор gcsim): мейны 5★, по 2 фиксированных
  ролла каждого сабстата и 20 «свободных» (не больше 10 на стат, минус 2 за каждый совпадающий мейн).
  Свободные роллы сначала идут в ВЭ до цели, потом в то, что больше всего поднимает урон. С *auto* пески,
  кубок и шапка выбираются сами.
- **Artifacts** — собираешь персонажа из своих артефактов: клик по слоту → выбор из списка (фильтр по сету
  и мейну, сортировка по крит-ценности / ВЭ / МС и т.д.). Артефакты, надетые на другого члена отряда,
  помечаются. Бонусы сетов считаются по надетым частям.
- **Custom stats** — точные цифры вручную (например, из импортированного конфига).

💾 на карточке сохраняет билд в **My builds**; оттуда его можно загрузить обратно на карточку или в другой отряд.

### Откуда взять артефакты

- **Artifacts → Import GOOD file** — файл формата GOOD из Genshin Optimizer, Inventory Kamera, Irminsul и т.п.
  Читаются только артефакты, персонажей собираешь сам.
- **Enka** — ввести UID и нажать *Load*. Подтягиваются персонажи из витрины в игре (в витрине должно быть включено
  «Показывать детали персонажа») и билды, сохранённые в привязанном профиле Enka. Персонажа можно сразу
  поставить в отряд, сохранить в *My builds* или добавить его артефакты в инвентарь (дубликаты не добавляются).
  Артефакты из сетов, которых нет в gcsim, импортируются со статами, но без бонуса сета.

### Ротация

Ротация делится на **Opener** (выполняется один раз) и **Rotation loop** (повторяется). Действия добавляются
в место мигающего курсора:

- кнопками персонажа (E, E hold, Q, N1…N6, CA/Aim, Plunge, Dash, Jump, Wait/Delay) или с клавиатуры;
- текстом: в поле над ротацией пишешь, например,
  `Nicole QE Citlali E Yelan Q N1 E N1 E N1 HuTao E 10N2CD Q` и жмёшь *Replace loop* (Enter),
  *Replace opener* или *Insert at cursor*. *Copy loop as text* копирует текущую ротацию в этой же записи.

Запись ротации текстом (регистр не важен):

| Запись | Значение |
| --- | --- |
| `HuTao`, `Hu Tao`, `hutao` | сменить персонажа (имя, ключ gcsim или короткое имя) |
| `N1`…`N6` | обычная атака из N ударов |
| `C` / `CA` | заряженная атака |
| `E` / `hE` | навык / навык с удержанием |
| `Q` | взрыв стихии |
| `D` / `J` | рывок / прыжок |
| `A` | прицельный выстрел (луки) |
| `P` / `LP` | атака в падении (высокая / низкая) |
| `10N2CD`, `10(N2 C D)` | повторить 10 раз |
| `Q?` | выполнить, только если готово |
| `[Q E \| E]?` | блок «если»: если взрыв готов — первая часть, иначе вторая (условие можно поменять потом) |
| `wait30` / `delay30` | подождать 30 кадров |

**Условия.** Любому действию можно задать *Only run if…*: ХП %, энергия, готов ли взрыв, сколько осталось
КД, сколько осталось статуса / модификатора, аура на враге, кто на поле, время сима, номер ротации и т.д.,
с объединением и/или. Пример: «Ху Тао ультует только если ХП < 50%» или «пропустить ульт в первой ротации».

**Блоки.** *If* (ветки then/else), *Repeat ×N* (превращается в `for`) и *Script* (сырой скрипт gcsim).
Блоки и действия перетаскиваются мышью, в том числе внутрь блоков и из них. Блок можно свернуть в фишку
вида `10(N2CD)` кнопкой ▾, а развернуть — кнопкой ▸ или двойным кликом.

### Цель и энергия

В настройках сима есть пресеты цели:

- **gcsim / KQMS default** — чистая частица каждые 8–12 с.
- **DPS Test Dummy++** (Miliastra Wonderland): *A12* — 1 белая сфера за 1,5М урона, старт с полной энергией;
  *SoF* — 2М, старт без энергии; *SoD* — 4М, старт без энергии. Белая сфера = 3 чистые частицы. gcsim
  ограничивает уровень цели сотней, поэтому SoF / SoD считаются на 100 уровне.

### Симуляция

Панель **Simulate** (gcsim должен быть скачан — `setup.bat` или кнопка *Download gcsim*):

- **Run sim** — ДПС, вклад каждого персонажа, время на поле, время ожидания (энергия / КД / смена),
  реакции, урон по источникам.
- **Check ER** — 24 прогона с взрывами по КД и подсчёт, сколько ВЭ нужно каждому (как в оптимизаторе gcsim).
  **Fix ER** сам поднимает или снижает цель ВЭ и перераспределяет сабстаты.
- **gcsim substat optimizer** — сабстаты KQMS по симуляции самого gcsim, сразу подставляются в билды.

### Таймлайны

- **Estimate** — обновляется на ходу, пока собираешь ротацию: кадры отмен, задержка смены, КД навыков,
  длительности эффектов. Без хитлага, энергии и ХП — это прикидка.
- **gcsim sample** — после сима: одна реальная итерация с хитлагом (например, продление стойки Ху Тао),
  все статусы и баффы, КД, графики энергии и ХП, каждый удар по стихии, ауры и реакции на враге, красной
  штриховкой — где gcsim ждал, потому что действие было не готово.

Таймлайн двигается перетаскиванием мышью, масштаб — **Ctrl + колёсико**, *Fit* вписывает всё целиком.

### Отряды, импорт и экспорт

- **Teams** — сохраняет текущий отряд в папку `teams/` (`<имя>.gcbuild.json` для загрузки обратно и
  `<имя>.txt` — готовый конфиг gcsim), показывает список, загружает и удаляет.
- **Import config** — вставить любой конфиг gcsim: билды сохраняют точные статы, строки ротации, `if/else`
  и `for` становятся редактируемыми блоками, остальное остаётся скриптом.
- **Export** / **Open** — сохранить / открыть проект JSON-файлом (*Open* принимает и конфиг `.txt`).

### Клавиатура

| Клавиша | Действие |
| --- | --- |
| `1`–`4` | выбрать персонажа |
| `E` / `Shift+E` | навык / навык с удержанием |
| `Q` | взрыв стихии |
| `A` | обычная атака (повторное нажатие — N2, N3…) |
| `C` | заряженная атака (прицельный для луков) |
| `P` / `D` / `J` | атака в падении / рывок / прыжок |
| `W` | ожидание (кадры из поля Timing) |
| `←` `→` | двигать курсор вставки |
| `Backspace` / `Delete` | удалить выбранное (или действие перед курсором) |
| `Ctrl+Z` / `Ctrl+Y` | отменить / повторить |
| `Ctrl+Enter` | запустить сим |

## Сообщить об ошибке

Кнопка **Report a bug** в шапке сайта открывает на GitHub новый issue, где уже заполнены версия сайта,
версия gcsim, браузер и конфиг текущего отряда. Допиши, что нажимал и что ожидал увидеть, и отправь.
Нужен аккаунт GitHub. Если его нет, нажми *Export* и пришли автору файл вместе с описанием.

Если сайт упал, на странице «Something broke» есть такая же кнопка **Report on GitHub** (туда сразу
попадает текст ошибки) и **Copy report** — скопировать тот же отчёт, чтобы прислать его другим способом.

## Если что-то не работает

- **Окно `start.bat` пишет ошибку.** Прочитай её: обычно это старый Node (обнови с nodejs.org) или
  `Port 5179 is already in use` — сайт уже запущен в другом окне, закрой его.
- **Страница «Something broke».** Отправь отчёт (см. выше). Если ошибка повторяется при каждом открытии,
  нажми **Reset current team**: сбрасывается только текущий отряд, артефакты, *My builds* и `teams/`
  остаются.
- **Пустая страница без сообщений.** F12 → вкладка *Console*, пришли скрин красных строк.
- **Нет иконок.** Они грузятся из интернета (gcsim.app), без сети будут пустые квадраты.
- **Пропали артефакты / билды.** Они хранятся в `userdata/` в папке проекта. Если сайт открыт не на
  http://localhost:5179/, браузер может показывать другие данные. Если в браузере осталась другая версия
  списка, в панели *Artifacts* / *My builds* появится кнопка восстановления.
- **Ничего не помогает.** Запусти `setup.bat` ещё раз, потом `start.bat`.

## Ограничения

- Таймлайн *Estimate* — подсказка для планирования: без хитлага, скорости атаки, энергии и ХП. Реальная
  картина — в *gcsim sample*.
- Быстрый KQMS — эвристика. Точнее: *Check ER* + *gcsim substat optimizer*.
- Импорт конфига переводит в блоки типичный скрипт; функции, `switch`, `while` с условиями и т.п. остаются
  сырым скриптом.
